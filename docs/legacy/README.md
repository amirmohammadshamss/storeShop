# Legacy reference archive

storeShop-cra.zip preserves the former CRA source, assets, templates, workers, static hosting rules, and Yarn lockfile. manifest.json records each original path, byte count, and SHA-256 digest. Contents were verified before originals were removed from active source/public paths.

Do not extract into the active project or deploy this archive. Use a separate temporary directory for historical comparison. Backend contracts were inferred from this source and still require live verification. Asset/font licenses remain unverified; the new UI uses system fonts and original SVG illustrations.
